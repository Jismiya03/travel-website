# Hillscape – Discover the Beauty of Kerala 🌴

Hillscape is a static travel website developed to showcase the scenic destinations, natural beauty, and tourist attractions of Kerala. It provides users with an engaging browsing experience through a clean design, attractive visuals, and easy navigation.

## 🌿 About the Project

The main objective of this project is to create a simple and visually appealing travel website that helps users explore popular tourist destinations in Kerala.

The website includes information about different destinations, along with dedicated pages to explore each location.

## ✨ Features

- **Home Page:** An attractive landing page introducing Kerala's beautiful destinations.
- **About Page:** Provides information about the website.
- **Destination Pages:** Dedicated pages featuring popular destinations such as:
  - Munnar
  - Alappuzha
  - Athirappilly
  - Varkala
  - Wayanad
- **Contact Page:** Provides a way for visitors to get in touch.
- **User-Friendly Navigation:** Simple and intuitive navigation between pages.
- **Responsive Design:** Designed to provide a better browsing experience across different screen sizes.
- **Visual Experience:** Uses images and nature-inspired styling to highlight Kerala's beauty.

## 🛠️ Technologies Used

- **HTML5** – For structuring the web pages.
- **CSS3** – For styling, layouts, and responsive design.
- **JavaScript** – For adding interactive functionality.
